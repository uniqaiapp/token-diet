# Contributing

Issues and pull requests are welcome. Keep changes small and include a before/after example in the PR description.

## Local checks

```bash
python3 tests/run.py
```

No packages to install; Python 3.9+ standard library only. The suite runs without network and in a few seconds. It pins every file under `examples/*/dry-run.txt`, `examples/*/report.txt` and `examples/transcript/breakdown.txt` byte-for-byte, so if you change a protection rule or an estimator rate, regenerate the fixtures and commit the diff:

```bash
for d in examples/*/; do
  [ -f "$d/before.txt" ] || continue
  python3 scripts/diet.py "$d/before.txt" --dry-run --provider openai > "$d/dry-run.txt"
  python3 scripts/measure.py "$d/before.txt" "$d/after.txt" --estimate > "$d/report.txt"
done
python3 scripts/measure.py --breakdown examples/transcript/transcript.sample.json --estimate > examples/transcript/breakdown.txt
```

## What a good contribution looks like

- A new protection rule comes with a test in `tests/test_protect.py` showing a real span it rescues and a Cyrillic (or other non-Latin) sentence it leaves alone.
- A new example is a prompt someone would actually type, plus a reference `after.txt` that keeps every protected span verbatim (`tests/test_scripts.py` checks this) and is shorter than the original.
- A new provider adds one branch in `build_request` and `extract_text`, a default cheap model in `PROVIDERS`, and a row in `references/providers.md`. Keys stay in environment variables.
- Numbers in README, CHANGELOG or issues come from `scripts/measure.py` with the method named. Do not paste percentages from blog posts.

## Rules that apply to every file

- Author and maintainer is UniqAI <support@uniqai.app>. No personal names in code, docs, examples or commit messages.
- No secrets, no key values, no `.env` files. Example prompts must not contain real customer data.
- Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`.
- English README is primary; keep `README.ru.md` in sync for user-facing changes.

## Deviations from org conventions

- The `.gitignore` names the Node dependency folder, which the forbidden-string test otherwise rejects; the test exempts that one file for that one string.
- Visual assets (`assets/banner*.svg`, `assets/demo.svg`, `assets/social-preview.png`) are generated by the org-level design kit, not by a script in this repo; `assets/demo.txt` is the terminal script that produced `demo.svg`.
- The Anthropic calls use `urllib` rather than the official SDK because the repo has a zero-dependency rule.
